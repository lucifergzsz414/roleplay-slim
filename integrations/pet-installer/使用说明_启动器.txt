roleplay-slim 通用版
长对话整理器 · Windows 使用说明

一、它能做什么

长时间和 AI 角色聊天时，聊天记录会越来越长。roleplay-slim 会保留角色设定和最近对话，只整理较早的历史内容，减少重复发送的上下文。

通用版适用于能够填写 OpenAI 兼容 API 地址的软件，例如 SillyTavern、OpenWebUI 和自行开发的聊天应用。


二、压缩包里有什么

roleplay-slim启动器.exe
    图形界面，用来选择模型服务、启动或停止整理服务、查看节省统计。

roleplay-slim-proxy.exe
    本地整理服务。必须和启动器放在同一个文件夹中。

使用说明_启动器.txt
    本说明。

请先完整解压压缩包，不要直接在压缩软件预览窗口中运行。

发布页还会提供 roleplay-slim-windows-x64.zip.sha256。它记录安装包的 SHA-256，
用于确认下载过程中文件没有损坏或被替换。在 PowerShell 中进入下载目录后运行：

    (Get-FileHash .\roleplay-slim-windows-x64.zip -Algorithm SHA256).Hash.ToLower()

输出应与 .sha256 文件开头的 64 位字符完全一致。校验文件不能替代 Windows
代码签名，因此仍请只从项目官方发布页下载安装包。


三、开始使用

1. 双击 roleplay-slim启动器.exe。

2. 在“AI 服务”中选择实际使用的服务商。
   预设包含 DeepSeek、OpenAI 和硅基流动，也可以选择自定义地址。
   “模型名称”留空时，会沿用聊天软件请求中的模型。

3. 在“接入应用”中选择“通用模式”。

4. 点击“复制地址”，把复制出的本地地址粘贴到聊天软件的“API 地址”或“Base URL”中。

5. API Key 仍然填写在原聊天软件里，不需要填进本启动器。

6. 点击“开始整理”，等待状态显示为正在运行。

7. 回到聊天软件发送一条测试消息。请求成功后，启动器中的处理次数和节省统计会发生变化。


四、如何确认接入成功

同时满足下面三项即可：

· 启动器状态显示正在运行。
· 聊天软件能够正常收到模型回复。
· 启动器中的处理次数不再是 0。

如果聊天能够回复，但处理次数始终为 0，通常说明聊天软件仍在使用原来的 API 地址。


五、停止使用和恢复

点击“停止整理”或关闭启动器，服务就会停止。

要恢复原来的连接方式，只需把聊天软件的 API 地址改回原服务商地址。通用模式不会修改系统代理、hosts、防火墙或注册表。

不再需要时，可以删除整个解压目录。运行数据位于同目录的 roleplay-slim-data 文件夹中。


六、隐私说明

· 启动器不会要求、读取或保存 API Key。
· 聊天软件发出的请求会经过本机整理服务，再转发给你选择的模型服务商。
· 本地服务需要在内存中处理对话内容，但不会把对话正文写入统计文件。
· 统计文件只用于记录处理次数和节省量。
· 默认只监听 127.0.0.1，不向局域网或公网开放端口。


七、常见问题

Q：Windows 提示“已保护你的电脑”怎么办？
A：当前测试版尚未购买代码签名证书。请确认文件来自项目官方发布页，并核对发布页提供的 SHA-256；确认一致后再选择“更多信息”继续运行。

Q：启动失败或一直停在“正在启动”怎么办？
A：确认 roleplay-slim-proxy.exe 与启动器在同一目录，并检查安全软件是否隔离了代理程序。

Q：聊天软件显示连接失败怎么办？
A：先确认启动器仍处于正在运行状态，再检查 API 地址是否完整粘贴，末尾应包含 /v1。

Q：模型名称应该填什么？
A：一般可以留空，让聊天软件继续决定模型。只有服务商要求固定模型时才填写。

Q：统计数字一直不变化怎么办？
A：说明请求没有经过本地地址。检查聊天软件当前保存的 API 地址，并重新发送一条测试消息。

Q：关闭窗口后还能聊天吗？
A：本地整理服务会一起停止。如果聊天软件仍指向本地地址，它会暂时无法连接；重新启动本程序，或把 API 地址改回原服务商即可。
