# roleplay-slim 0.5.0 通用版 Windows 测试版

这次主要修复旧消息中间的事实被默认截取删除的问题。

## 改了什么

- 默认保留全部对话正文，不再只保留旧消息的首尾句。
- 摘要报错、返回空白或格式错误时保留原文；摘要函数拿到的是副本，不能因修改后失败破坏原文。
- Anthropic 旧工具结果默认保留，裁剪改为主动开启的有损选项。
- 通用启动器和示例配置同步使用保留策略；代理增加 `--version`，报告 `0.5.0`。
- 旧配置若仍启用截取、丢弃、动作删除或 token 预算，启动日志会提示事实损失风险。

## 实测与限制

- 本机完整测试 311 项通过，包含已安装 DSH 适配器协议测试和新包代理烟测。
- 新 ZIP 解压后，包中代理的普通请求、中文流式回复、旧消息中间事实和工具结果保留均通过。
- 同一合成样本的真实 DeepSeek 测试，事实回答从旧默认的 4/5 恢复为 5/5。
- 该样本输入恢复为 2785 tokens，没有压缩收益。优先保留事实不等于任意内容都能无损压缩，也不保证模型一定记住。
- 没有真实 QQ/微信端到端验收，不宣称全面适配所有 DSH 版本或账号登录方式。

## 升级方法

1. 关闭旧启动器。
2. 下载 `roleplay-slim-windows-x64.zip`，完整解压到新目录。
3. 双击新目录里的 `roleplay-slim启动器.exe`，重新选择服务商并开始整理。
4. 不要把旧版 `config.toml` 复制到新目录覆盖默认配置。

API Key 仍填写在原聊天软件，不需要交给启动器。程序默认只监听本机回环地址，
不修改系统代理、hosts、防火墙或注册表。桌宠专用安装器没有更新，旧目录保留即可回退。

## 校验

下载同页的 `.sha256` 文件。在 PowerShell 中运行：

```powershell
(Get-FileHash .\roleplay-slim-windows-x64.zip -Algorithm SHA256).Hash.ToLower()
```

应为：

```text
fab7d7b74486ad95d2430d07f9203ed6592059d4afd8a6fb6816131d491055c5
```

当前仍是未进行 Windows 代码签名的测试版。SHA-256 用于核对文件，不等于签名或完整安全审计。
