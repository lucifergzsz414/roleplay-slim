若叶睦桌宠 · 上下文优化代理 — 使用说明
========================================

【安装】
1. 解压这个 zip 到任意文件夹（安装器.exe 和 roleplay-slim-proxy.exe 必须放在同一目录下，不要分开）
2. 双击「安装器.exe」
3. 选择桌宠安装目录（自动检测不到的话点"浏览..."手动选）
4. 确认 DeepSeek API Key（一般会自动从注册表读出来）
5. 点击「开始安装」，等日志走完、弹出"安装完成"

【日常使用】
安装完成后，桌宠目录下会多出一个「若叶睦.bat」——以后启动桌宠都双击这个文件，不用再碰安装器。

启动流程：若叶睦.bat 会自动拉起上下文压缩代理 → 等代理就绪 → 启动桌宠本体。

【怎么关闭】
直接正常关闭桌宠本体就行，代理会自动跟着关闭，不需要手动做任何事。

【重新安装 / 升级】
以后拿到新版本的 zip，可以直接对着同一个桌宠目录再装一遍——原始游戏文件的 patch 和备份不会受影响，只会更新代理程序和启动脚本。

重装前请确保桌宠和代理都已经关闭（不要在桌宠还开着的时候重装）。

【卸载 / 还原】
不想用了，或者想彻底恢复到没装过代理的状态，双击「卸载还原器.exe」：
1. 选择桌宠安装目录
2. 点击「卸载 / 还原」，确认弹窗
3. 等日志走完

会做的事：把游戏文件（level0 / metadata）从备份还原回官方原版，删除代理程序、配置和两个启动脚本（启动代理.bat、若叶睦.bat）。
不会做的事：不会删除备份文件本身（level0.bak / global-metadata.dat.bak），万一还原出问题这两个文件还在，可以手动恢复。

卸载前同样建议先关闭桌宠和代理，避免文件被占用导致部分文件删不掉（工具会自动尝试停止代理进程，一般不用你操心）。

【常见问题】

Q: 重新安装后感觉没生效（比如看不到日志、行为跟以前一样）？
A: 可能是旧版本的代理进程还在后台占着，导致新文件没能覆盖成功。
   打开任务管理器（Ctrl+Shift+Esc）→ 搜索"roleplay-slim-proxy" → 结束任务 →
   重新运行安装器（或者重新双击 若叶睦.bat）。

Q: 双击若叶睦.bat 后卡在"等待代理就绪"？
A: 可能是杀毒软件拦截了代理程序，尝试关闭杀毒软件后重试。

Q: 想看代理的运行日志（比如压缩了多少 token）？
A: 代理启动后会有一个「roleplay-slim-proxy」标题的控制台窗口（默认最小化在任务栏），
   点开就能看到每次对话的压缩统计。

Q: 装完之后，代理 healthz 正常、但一直没收到桌宠的请求（/stats 里 request_count 一直是 0）？
A: 若叶睦桌宠 1.9.5 及以上版本新增了"动态 API 地址"设置，会在启动时从注册表读取这个设置、
   覆盖掉安装器 patch 进游戏文件里的默认地址。本安装器已经会自动检测并同步 patch 这个注册表设置
   （老版本 1.9.0 没有这个设置，检测不到会自动跳过，不影响使用）。
   如果你用的是更新的安装包却还遇到这个问题，请重新跑一遍安装器确认没有报错。
